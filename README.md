# Electricity Price Forecast

Projekt prognozowania cen energii elektrycznej na polskim rynku dnia nastepnego.

## Cel

Prognozowanie godzinowego profilu cen na kolejny dzien oraz porownanie
metod bazowych, ekonometrycznych i uczenia maszynowego.

## Technologie

- Python 3.12
- pandas, NumPy
- statsmodels, scikit-learn
- Matplotlib
- Streamlit
- ENTSO-E Transparency Platform API

## Konfiguracja

1. Utworz i aktywuj srodowisko wirtualne `.venv`.
2. Zainstaluj zaleznosci z `requirements.txt`.
3. Skonfiguruj klucz API lokalnie, nie umieszczajac go w repozytorium.

## Bezpieczenstwo

Nie dodawaj do repozytorium kluczy API, plikow `.env`, danych surowych
ani lokalnych artefaktow modeli.
